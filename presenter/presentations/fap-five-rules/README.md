# עיצוב התהליך — Five Rules of FAP

A bilingual (Hebrew RTL / English) presentation on the **Five Rules of Functional
Analytic Psychotherapy (FAP)**, rebuilt from the supplied reference deck.

## View it

Open `output/index.html` in any modern browser (it loads Reveal.js from a CDN,
so an internet connection is needed the first time).

- `→ / Space` next · `←` previous · `Esc` slide overview · `F` fullscreen
- Each rule has vertical sub-slides — press `↓` to drill into a rule's detail.
